## 三、结论

1. **LLM 精排在改述题上依然是最大功臣**：Hit@3 0.633（混合）→ 0.900（全链路，+26.7pp），
   Hit@1 0.400 → 0.767（+36.7pp）；直述题上也有小幅提升。关键词融合在改述题上仍是负贡献
   （Hit@3 0.767→0.633），与 2026-08-07 结论一致。
2. **与旧口径（2026-08-07，1617 chunks，512 原始窗口）的差异**：
   - 命中率基本持平：改述题 Hit@5 仍 0.933；Hit@3 0.933→0.900。
   - **片段级 Recall@5 下降**：0.867 → 0.734（改述题）。原因：512→256 细化后每条 query 的
     相关片段变多、片段级召回分母变大；Recall@K 天然惩罚细粒度分块。用户体感（命中率）未变。
3. **标题并回 chunk 文本 + 系统扫参定 256/64 的收益**：ground-truth 标注 0 警告（7 条"答案在标题行"
   的标注此前永远无法命中，现已全部可命中）；检索链路在此基础上的三档对比见上表。
4. 简历/口播口径建议统一用本文件数字（2026-08-17）：改述题 Top-5 命中率 93.3% / Top-3 90% / MRR@5 0.84。
